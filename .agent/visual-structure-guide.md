## Info Box Types - Visual Reference

### 📘 Info Box (Blue)

```
┌─────────────────────────────────────────────────────────────────┐
│ 📘 What You'll Learn                                            │
│ Used for: Key takeaways, definitions, important concepts       │
│ Color: Light blue background (#e3f2fd)                         │
└─────────────────────────────────────────────────────────────────┘
```

### 💡 Tip Box (Green)

```
┌─────────────────────────────────────────────────────────────────┐
│ 💡 Pro Tip                                                      │
│ Used for: Best practices, optimizations, helpful hints         │
│ Color: Light green background (#e8f5e9)                        │
└─────────────────────────────────────────────────────────────────┘
```

### ⚠️ Warning Box (Red)

```
┌─────────────────────────────────────────────────────────────────┐
│ ⚠️ Important Warning                                            │
│ Used for: Gotchas, breaking changes, critical issues           │
│ Color: Light red background (#ffebee)                          │
└─────────────────────────────────────────────────────────────────┘
```

### 📋 Example Box (Orange)

```
┌─────────────────────────────────────────────────────────────────┐
│ 📋 Example Scenario                                             │
│ Used for: Introducing real-world scenarios before code         │
│ Color: Light orange background (#fff3e0)                       │
└─────────────────────────────────────────────────────────────────┘
```


## Word Count Distribution

```
Total Article: 2,000-2,500 words (100%)
│
├─ Introduction ────────────── 250-375 words (12-15%)
│  └─ Info box with takeaways
│
├─ Background ─────────────────200-300 words (10-12%)
│
├─ Main Content ───────────── 1,250-1,500 words (50-60%)
│  ├─ Section 1 (400-500 words)
│  ├─ Section 2 (400-500 words)
│  └─ Section 3 (400-500 words)
│
├─ Real-World Example ────────375-500 words (15-20%)
│  └─ Step 1, Step 2, Step 3
│
├─ Troubleshooting ───────────250-350 words (10-14%)
│  └─ 3-5 common issues
│
├─ Best Practices ────────────125-175 words (5-7%)
│  └─ 5-7 actionable practices
│
├─ Resources (optional) ──────75-100 words (3-4%)
│
└─ Conclusion ────────────────125-175 words (5-7%)
```

## Minimum Requirements

Every article MUST have:

- ✅ 2,000-2,500 words
- ✅ 4-6 complete code examples
- ✅ 1+ comparison table
- ✅ 1 info box (What You'll Learn)
- ✅ 2+ additional boxes (tip/warning/example)
- ✅ 1 feature grid OR additional table
- ✅ Syntax highlighting on ALL code
- ✅ Banner image reference
- ✅ Troubleshooting section
- ✅ Best practices section
- ✅ title.txt file
- ✅ image-prompts-table.md file

## Visual Element Spacing

```
BANNER
  ↓ 30px margin
TITLE
  ↓ 15px margin
SUBTITLE
  ↓ 10px margin
META INFO
  ↓ 40px margin

SECTION CARD (white background, shadow)
  ↓ 30px margin between sections

  Inside each section:
  - 40px padding all around
  - H2: 0 top margin, 25px bottom margin
  - H3: 30px top margin, 15px bottom margin
  - Paragraphs: 1.5rem bottom margin
  - Code blocks: 1.5rem top/bottom margin
  - Info boxes: 1.5rem top/bottom margin
  - Tables: 25px top/bottom margin
```

## Typography Scale

```
H1 (Title):       2.5rem (40px) - Gradient, bold 800
Subtitle:         1.2rem (19.2px) - Gray, normal 400
Meta Info:        0.9rem (14.4px) - Light gray

H2 (Section):     1.8rem (28.8px) - Red, bold 700
H3 (Subsection):  1.4rem (22.4px) - Blue, bold 600
H4 (Sub-sub):     1.1rem (17.6px) - Dark, bold 600

Paragraph:        1.05rem (16.8px) - Line height 1.8
Code inline:      0.95em - Monospace, gray background
Code block:       1rem - Monospace, dark background

Line Height:
- Headings: 1.2
- Body text: 1.8
- Code: 1.5
```

## Responsive Breakpoints

```
Desktop (default):  900px max-width container
                    40px section padding
                    Full-size images

Tablet (< 1024px):  Container adapts
                    Maintained padding

Mobile (< 768px):
  - H1: 2rem (down from 2.5rem)
  - Section padding: 25px (down from 40px)
  - Container padding: 15px (down from 20px)
  - Tables: 0.9rem font (down from 1.05rem)
  - Feature grid: 1 column (down from auto-fit)
```
