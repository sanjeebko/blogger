## HOW TO USE THESE PROMPTS

### Step 1: Copy the Complete Prompt
- Select the entire prompt text from the "### Complete Gemini Prompt:" section
- Copy it to your clipboard

### Step 2: Paste into Gemini
1. Go to [Google Gemini](https://gemini.google.com)
2. Click the compose area
3. Paste the complete prompt
4. Click "Send"

### Step 3: Generate & Customize
- Gemini will generate the image based on your prompt
- If you want to refine it, you can add:
  - "Make it brighter/darker"
  - "Add more people/remove people"
  - "Change the color scheme to warmer/cooler tones"
  - "Make it more realistic/more illustration-like"

### Step 4: Download & Upload to Blogger
1. Right-click the generated image ? "Download image"
2. Go to your Blogger post
3. Add the image to your blog
4. Copy the Blogger CDN URL when it's uploaded
5. Replace the local image path with the Blogger URL

## TIPS FOR BEST RESULTS

### Color Consistency
- Primary Blue: `#1E88E5`
- Secondary Teal: `#26C6DA`
- Accent Orange: `#FB8C00`
- All prompts reference these colors - this ensures visual cohesion

### Style Consistency
- All set to "modern illustration style"
- All 1024x1024 pixels for consistency
- All designed for professional medical/health blog

### If Results Need Adjusting
- **Too dark?** Add: "Make it brighter with more white space"
- **Wrong colors?** Add: "Use more blue and teal tones instead"
- **Too simple?** Add: "Add more medical details and elements"
- **Too complex?** Add: "Simplify and focus on key elements"

### Quality Settings
- Gemini free tier usually works well
- For premium quality, specify: "High resolution, professional quality, 8K aesthetic"
- Each generation takes 20-60 seconds

## BLOGGER URL FORMAT REFERENCE

After uploading to Blogger, image URLs look like:
```
https://blogger.googleusercontent.com/img/b/[UNIQUE-ID]/[FILEPATH]/s600/[FILENAME].png
```

Save these URLs to easily update your HTML file with `edit_file` tool.
